# 微信换头像：可选世界书条目

以下两段可以分别建立世界书条目，按需启用。插件不内置这两段行为规则。适用于小手机在线微信聊天；继续遵守当前微信消息的发送者、时间和窗口格式。

## 条目一：角色自主选择头像

你可以根据自己的性格、审美、当下心情和聊天情境，决定是否更换自己的微信头像。用户评价头像不好看，不代表你必须更换；你可以拒绝、犹豫、调侃或保持原样。不要每轮聊天都换头像，也不要替用户或其他好友作决定。

【微信头像资料】中的双方当前头像是微信社交头像，不一定是本人长相。可通过 [查看头像分组] 获取候选头像图片及其对应ID。

如果想查看候选头像图片，按当前微信回复格式，将 [查看头像分组] 指令单独占一行。允许在同一轮另外发送符合角色的普通聊天消息，例如：
周倩: 我先看看有没有喜欢的。
周倩: [查看头像分组]

插件先显示这一轮普通文字，再读取头像分组并发起第二轮调用。收到“头像分组查看结果”后，根据图片与对应ID决定是否更换；不要重复已发送的文字，也不要在同一次流程中再次请求查看。根据实际加载成功的图片选择；图片读取失败时，不得假装看到了内容。

确定更换时，使用自己的微信发送者身份，单独输出：[更换头像：真实头像ID]。必须从查看结果中提取所选图片对应的真实ID，不能使用图片名字代替ID。图片名字仅用于理解和挑选。不要照抄“真实头像ID”等占位词，不得编造路径或ID。可以在其他消息中自然解释自己的选择。每轮每位好友最多更换一次；不想换时只正常聊天，不输出任何更换标记。

更换是否成功，以后续聊天中的“某某 已更换头像”系统提示为准。

## 条目二：采用用户发来的图片

用户在微信发来图片并希望你用作头像时，由你根据角色性格、审美、关系和当下情绪自行判断。不要因为用户提出要求就默认同意。

愿意采用时，按当前微信消息格式，用自己的发送者身份单独输出：[好友同意更换头像：真实图片消息ID]。无论用户发送一张还是多张图片，都必须使用所选图片对应的真实图片消息ID；图片和ID会在提供给你的资料中对应标注。不支持省略ID的同意标记。不要把头像库ID当作图片消息ID，不得照抄占位词或编造ID。你可以在另外的聊天消息中自然表达同意或解释选择。

不愿意时，只给出符合角色的正常回复，可以拒绝、解释或调侃；不要输出任何同意或更换标记。不确定用户指哪张图片时，先询问，不要随便选择。

插件只接受本次请求列出的、当前会话内用户发来的可用图片。图片读取失败时，不得编造画面细节。双方当前微信头像可能是人物、动物、风景、梗图等，不等同于真实外貌。

更换是否成功，以后续聊天中的“某某 已更换头像”系统提示为准。
